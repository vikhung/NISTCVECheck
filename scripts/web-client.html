CVE Web Scanner 提供三個頁籤，說明如下。

📁 CVE掃描
  1. 填寫掃描設定（NIST API Key 選填、最低嚴重度、CVE 最早年份），設定會自動儲存於瀏覽器
  2. 上傳 scan.json（由 cve-checker.js 或 findSW.ps1 在目標機器上產生）
  3. 設定白名單（Publisher 關鍵字，符合條件的軟體略過掃描）
  4. 如有其他（Portable）軟體，於第 3 步手動加入名稱與版本
  5. 點擊「▶ 開始掃描」，完成後可在新分頁開啟報表，或下載 HTML / JSON 結果
🔍 CVE 查詢

查詢系統本機已快取的 CVE 資料——任何一次掃描（不論是這台伺服器或其他人執行過的）查過的軟體，都會留下記錄，可在此直接查詢，不需要重新掃描。

  • 輸入軟體名稱關鍵字（例：putty）或完整 CVE ID（例：CVE-2024-12345）
  • 可加上最低嚴重度、最早年份篩選結果
  • 僅伺服器代理模式可用：獨立模式（直接雙擊開啟本檔案）無法讀取伺服器本機的快取資料
